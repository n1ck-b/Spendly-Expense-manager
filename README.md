# Spendly

Spendly — это мобильное приложение для учёта личных расходов.  
Оно помогает быстро фиксировать траты, распределять их по категориям, анализировать статистику и управлять бюджетом.

**Операционная система:** Android  
**Язык разработки:** Kotlin  
**Язык интерфейса:** XML  

## Основные возможности
- Добавление расходов с указанием суммы, категории, даты, валюты и комментария.  
- Просмотр истории расходов с фильтрацией по периодам (сегодня, неделя, месяц, всё время).  
- Управление категориями расходов (создание, изменение, удаление, выбор иконки и цвета).  
- Просмотр статистики расходов в виде диаграммы.  
- Поддержка нескольких валют с автоматической конвертацией через [ExchangeRate-API](https://www.exchangerate-api.com/docs/overview).
