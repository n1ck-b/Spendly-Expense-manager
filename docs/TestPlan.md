<a name="introduction"/>

## Введение

Данный документ описывает план тестирования мобильного приложения ["Spendly"](./) для ОС Android. Документ предназначен для команды, выполняющей тестирование данного проекта. Цель тестирования - проверка соответствия реального поведения программы и ее ожидаемого поведения, которое описано в [требованиях](./SRS.md).

<a name="items"/>

## Объект тестирования

В качестве объектов тестирования можно выделить следующие функциональные требования:
*   Управление расходами (добавление, изменение, удаление);
*   Управление категориями расходов (создание, изменение, удаление);
*   Просмотр истории расходов и фильтрация по времени;
*   Просмотр статистики расходов в виде диаграммы;
*   Конвертация валют при добавлении расхода.

<a name="quality"/>

## Атрибуты качества

1.  **Функциональность**:
    *   Функциональная полнота: приложение должно выполнять все заявленные функции, связанные с учётом расходов.
    *   Функциональная корректность: приложение должно корректно выполнять все заявленные функции (расчёты, сохранение, удаление).
2.  **Удобство использования**:
    *   Интерфейс должен быть простым и интуитивно понятным, соответствовать предоставленным [макетам](./SRS.md#22-интерфейс-пользователя).
    *   Все функциональные элементы пользовательского интерфейса должны иметь понятные названия.
3.  **Безопасность**:
    *   Данные пользователя должны храниться локально на устройстве и не передаваться на внешние серверы.
4.  **Доступность**:
    *   Приложение должно корректно работать на устройствах с различными характеристиками (размер экрана, версия ОС Android).
    *   Время отклика на действия пользователя должно быть минимальным.

<a name="risk"/>

## Риски

К рискам можно отнести:
*   Невозможность конвертации валюты без активного подключения к Интернету.
*   Некорректная работа приложения или ошибки при получении данных от внешнего API курсов валют (ExchangeRate-API).
*   Проблемы с отображением интерфейса на устройствах с нестандартным разрешением экрана.
*   Потеря данных при сбое приложения, так как все данные хранятся локально.

<a name="features"/>

## Аспекты тестирования

В ходе тестирования планируется проверить реализацию основных функций приложения, описанных в SRS:
*   Управление расходами
*   Управление категориями расходов
*   Просмотр истории и статистики
*   Конвертация валют

<a name="feature_1"/>

### Управление расходами
Этот аспект необходимо протестировать на:
*   Добавление нового расхода (корректное сохранение суммы, категории, даты, валюты и комментария).
*   Редактирование существующего расхода.
*   Удаление существующего расхода.

<a name="feature_2"/>

### Управление категориями расходов
Этот аспект необходимо протестировать на:
*   Создание новой категории (с выбором названия, иконки и цвета).
*   Редактирование существующей категории.
*   Удаление существующей категории и корректное переназначение расходов из неё в категорию «Без категории».

<a name="feature_3"/>

### Просмотр истории и статистики
Этот аспект необходимо протестировать на:
*   Корректное отображение списка расходов.
*   Работу фильтрации по времени (сегодня, неделя, месяц, всё время) в истории и на экране категорий.
*   Корректное отображение статистики в виде диаграммы и процентного соотношения трат по категориям.
*   Работу фильтрации по времени на экране статистики.

<a name="feature_4"/>

### Конвертация валют
Этот аспект необходимо протестировать на:
*   Успешную конвертацию суммы расхода в основную валюту при наличии подключения к Интернету.
*   Поведение приложения при попытке конвертации валюты без подключения к Интернету.

<a name="nonfunctional_requierements"/>

## Нефункциональные требования:
*   Соответствие интерфейса макетам, описанным в SRS.
*   Корректное отображение на разных размерах экранов и версиях Android.
*   Интуитивная понятность интерфейса и скорость отклика.

<a name="approach"/>

## Подходы к тестированию

При тестировании будет использован ручной подход на реальных устройствах и эмуляторах с разными версиями ОС Android.
