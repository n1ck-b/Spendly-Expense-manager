# Результаты тестирования

| Сценарий | Действие | Ожидаемый результат | Фактический результат | Оценка |
|:---|:---|:---|:---|:---|
| **1. Управление расходами** | - | - | - | - |
| 001-1: Добавление нового расхода | 1. Нажать кнопку добавления расхода <br> 2. Ввести сумму, выбрать категорию, дату <br> 3. Нажать "Сохранить" | Новый расход появляется в общем списке истории расходов | Новый расход появляется в общем списке истории расходов | Тест пройден |
| 001-2: Редактирование расхода | 1. Выбрать расход из списка <br> 2. Изменить сумму и комментарий <br> 3. Нажать "Сохранить" | Измененная информация отображается в списке расходов | Измененная информация отображается в списке расходов | Тест пройден |
| 001-3: Удаление расхода | 1. Выбрать расход из списка <br> 2. Нажать кнопку "Удалить" <br> 3. Подтвердить действие | Расход исчезает из общего списка | Расход исчезает из общего списка | Тест пройден |
| 001-4: Добавление расхода в другой валюте | 1. Добавить расход, выбрав валюту USD <br> 2. Убедиться, что есть интернет-соединение | Расход сохраняется в списке, сумма отображается в основной валюте по текущему курсу | Расход сохраняется в списке, сумма отображается в основной валюте по текущему курсу | Тест пройден |
| **2. Управление категориями** | - | - | - | - |
| 002-1: Создание новой категории | 1. Перейти на экран "Категории" <br> 2. Нажать "Добавить", ввести имя, выбрать цвет и иконку <br> 3. Сохранить | Новая категория появляется в общем списке категорий | Новая категория появляется в общем списке категорий | Тест пройден |
| 002-2: Редактирование категории | 1. Выбрать категорию <br> 2. Изменить название и цвет <br> 3. Сохранить | Измененная информация отображается в списке категорий | Измененная информация отображается в списке категорий | Тест пройден |
| 002-3: Удаление категории | 1. Выбрать категорию, в которой есть расходы <br> 2. Нажать "Удалить" и подтвердить | Категория исчезает из списка. Расходы, ранее принадлежавшие ей, теперь помечены как "Без категории" | Категория исчезает из списка. Расходы, ранее принадлежавшие ей, теперь помечены как "Без категории" | Тест пройден |
| **3. Просмотр истории и статистики** | - | - | - | - |
| 003-1: Фильтрация истории расходов | 1. Перейти на главный экран <br> 2. Переключить фильтр с "Месяц" на "Сегодня" | В списке отображаются только расходы, добавленные сегодня | В списке отображаются только расходы, добавленные сегодня | Тест пройден |
| 003-2: Отображение статистики | 1. Перейти на экран "Статистика" <br> 2. Выбрать фильтр "Месяц" | Отображается круговая диаграмма с расходами по категориям и процентами за текущий месяц | Отображается круговая диаграмма с расходами по категориям и процентами за текущий месяц | Тест пройден |
| 003-3: Фильтрация на экране категорий | 1. Перейти на экран "Категории" <br> 2. Переключить фильтр на "Неделя" | Суммы расходов напротив каждой категории пересчитываются для последней недели | Суммы расходов напротив каждой категории пересчитываются для последней недели | Тест пройден |
| **4. Обработка исключений** | - | - | - | - |
| 004-1: Конвертация валют без интернета | 1. Отключить интернет-соединение <br> 2. Попробовать добавить расход в валюте, отличной от основной | Приложение отображает предупреждение о невозможности конвертации и не позволяет сохранить расход до восстановления связи | Приложение отображает предупреждение о невозможности конвертации и не позволяет сохранить расход до восстановления связи | Тест пройден |
| 004-2: Ввод некорректной суммы | 1. На экране добавления расхода попытаться ввести текст в поле суммы | Поле суммы не принимает нечисловые значения | Поле суммы не принимает нечисловые значения | Тест пройден |

## Замечания
* Интерфейс соответствует макетам из SRS.
* Приложение стабильно работает на Android версий 10, 11 и 12.
* При медленном интернет-соединении есть небольшая задержка при конвертации валюты, стоит рассмотреть добавление индикатора загрузки.
